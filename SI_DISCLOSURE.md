# Use of Super Intelligence (SI)

## SI tools used
- **Claude Code** (Anthropic), used inside Visual Studio Code

## Where SI-generated content appears
- **Code:** most of the source code was written with Claude Code. Each code file has an SI-disclosure header.
- **Text:** README, documentation and knowledge-base summaries were drafted with Claude Code.
- **Data:** the crew health data is synthetic, generated by code written with Claude Code. The NASA OSDR dataset (OSD-575) is used unchanged and is not SI-generated.
- **Images:** none are SI-generated. Screenshots are captures of the running app.
- **In the app:** the AI assistant can optionally connect to the Claude API, but no API key is used in our demo or on the live site, so it runs in rule-based mode.
- No NASA logos or branding are used.

## Human contributions (team Orbit & Co)
- Choosing the challenge and concept
- Product and privacy decisions (NASA-aligned need-to-know rules, two Crew Medical Officers, onboard-first design)
- Architecture design and code structure decisions
- Test data review
- Directing and reviewing the SI-generated code
- Testing every feature
- Selecting NASA resources and datasets
- Creating the GitHub project and publishing it publicly
- Hosting the live app on Render
- Preparing the demo and submission
